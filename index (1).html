If this message stays on screen, the dashboard has not been connected to a repository yet. To connect it:

  1. Put this website in a GitHub repository.
  2. Open admin/config.yml and replace YOUR-GITHUB-USERNAME/YOUR-REPO-NAME with the real repository.
  3. Deploy the site on Netlify and turn on Identity and Git Gateway in the Netlify site settings.
  4. Invite yourself as a user under Identity, accept the email, then come back here and log in.

Full walkthrough in DASHBOARD-SETUP.md.
